# Governance

OpenSteamOpt currently uses a maintainer-led model. Abhijith Sivaprasadan is the initial
maintainer and release steward.

Technical decisions favour transparent assumptions, open-source dependencies,
reproducible evidence, backward-compatible interfaces and conservative industrial-safety
boundaries. Significant model changes should be proposed in an issue and document units,
assumptions, verification and migration impact.

The maintainer may delegate review areas and add maintainers based on sustained,
constructive contributions. Release tags require passing CI, updated changelog and
documentation, and a review that claimed features match committed evidence.
